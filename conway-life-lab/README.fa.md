# Conway Life Lab

یک محیط تعاملی و متن‌باز برای اجرای **بازی زندگی کانوی (Conway's Game of Life)** در مرورگر. هستهٔ شبیه‌سازی از رابط گرافیکی جدا شده و آزمون‌های خودکار دارد.

> **وضعیت:** نسخهٔ اولیهٔ `v0.1.0`. مسیر پژوهشی موجود در مستندات، برنامهٔ آینده است؛ در این نسخه ادعای کشف علمی جدیدی نداریم.

## امکانات

- اجرا، توقف و پیش‌برد شبیه‌سازی نسل‌به‌نسل
- روشن و خاموش‌کردن سلول‌ها با کلیک یا لمس
- بارگذاری الگوهای Glider، Blinker، Toad، Beacon، R-pentomino، Pulsar و Gosper Glider Gun
- ساخت صفحهٔ تصادفی با چگالی قابل تنظیم
- انتخاب صفحه از ۲۰×۲۰ تا ۸۰×۸۰
- مقایسهٔ مرزهای محدود با مرزهای دورپیچ (toroidal)
- مشاهدهٔ شمارهٔ نسل و تعداد سلول‌های زنده
- ذخیره و بازیابی وضعیت شبیه‌سازی در فایل JSON
- آزمون خودکار هستهٔ شبیه‌سازی با Node.js، بدون وابستگی زمان اجرا به کتابخانه‌های شخص ثالث

## اجرای محلی

به‌دلیل استفاده از JavaScript ES Modules، بهتر است فایل را از طریق یک وب‌سرور محلی باز کنید و مستقیماً روی `file://` دوبار کلیک نکنید.

اگر Python نصب است، در پوشهٔ پروژه اجرا کنید:

```bash
python -m http.server 8000
```

سپس در مرورگر به <http://localhost:8000> بروید.

## اجرای آزمون‌ها

Node.js نسخهٔ ۲۰ یا جدیدتر را نصب کنید و در پوشهٔ پروژه اجرا کنید:

```bash
npm test
```

آزمون‌ها قواعد تولد و بقا، الگوی ثابت، نوسان‌گر Blinker، رفتار مرزها، عدم تغییر ورودی تابع نسل بعد، بارگذاری الگوها، تولید تصادفی قابل‌کنترل و اعتبارسنجی فایل وضعیت را بررسی می‌کنند. GitHub Actions نیز همین آزمون‌ها را هنگام push و pull request اجرا می‌کند.

## انتشار در GitHub Pages

۱. یک مخزن عمومی با نام `conway-life-lab` بسازید.
۲. **محتویات این پوشه** را در ریشهٔ مخزن بارگذاری کنید؛ فایل‌ها و پوشه‌ها را بارگذاری کنید، نه فایل ZIP را به‌عنوان یک فایل واحد.
۳. در مخزن به **Settings → Pages** بروید.
۴. در بخش انتشار، گزینهٔ **Deploy from a branch**، شاخهٔ `main` و پوشهٔ `/(root)` را انتخاب و ذخیره کنید.
۵. پس از پایان انتشار، نشانی نمایش‌داده‌شده در همان صفحه را باز کنید.

## قواعد بازی

برای هر سلول، هشت همسایه بررسی می‌شوند:

۱. سلول زنده با ۲ یا ۳ همسایهٔ زنده باقی می‌ماند.
۲. سلول مرده با دقیقاً ۳ همسایهٔ زنده متولد می‌شود.
۳. در تمام حالت‌های دیگر، سلول در نسل بعد مرده خواهد بود.

با فعال‌کردن گزینهٔ wrap-around، لبه‌های بالا و پایین و نیز چپ و راست به یکدیگر متصل در نظر گرفته می‌شوند.
